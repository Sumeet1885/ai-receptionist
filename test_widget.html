CORS & Local Testing Requirements
  • Avoid File URLs: Do NOT open this file directly as file://.... Browsers send a null origin, which our strict widget CORS checks will immediately reject with a 403 Access Denied.
  • Use a Local Server: Serve this file using an HTTP server (e.g. VS Code's Live Server, npx http-server, or python -m http.server).
  • Update Allowed Domains: You must configure the origin of this test page (e.g., http://127.0.0.1:5500 or http://localhost:8080) in your Bot's settings (Allowed Domains) in the DB/Dashboard.
  • Start Local Server: Make sure your backend server is running on port 4000 (npm run dev in the server folder).
